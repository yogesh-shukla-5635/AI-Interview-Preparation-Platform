# AI Interview Preparation Platform

An AI-powered web application designed to help students and job seekers prepare for technical interviews.

The platform provides category-based mock interviews, AI-generated questions, answer evaluation, resume analysis, interview history, and certificate generation.

## Features

- AI-generated interview questions
- Category-based mock interviews
- Python interview preparation
- SQL interview preparation
- Artificial Intelligence interview preparation
- Machine Learning interview preparation
- AI-based answer evaluation
- Interview score generation
- Strengths and weaknesses analysis
- Improvement suggestions
- Resume analysis
- Interview history
- User authentication
- User profile management
- PDF certificate generation
- Unique certificate ID
- QR code generation for certificates
